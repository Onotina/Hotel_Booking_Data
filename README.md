# Hotel_Booking_Data

## Overview
This repository contains hotel chain booking data; the goal is to use data analytics to increase customer satisfaction and maximize revenue. 

The dataset, covering 2018 to 2020, includes information on various aspects of hotel bookings (from booking details to guest demographics). It includes Average Daily Rate (ADR), number of guests, booking agency, arrival details, room assignments, country, booking changes, and more. 

The main goal is to find insights into booking patterns, guest demographics, and operational efficiencies.

## Files
- **Hotel_Booking_Data.xlxs**: Contains the hotel booking data from 2018 to 2020, data dictionary
- **README.md**: This contains an overview of the repository
